
# 💻 Portfólio Pessoal — Israel Cardoso

## 📌 Sobre o projeto

Este projeto é um portfólio pessoal desenvolvido para apresentar minha biografia, qualidades, habilidades e trabalhos realizados durante minha trajetória de aprendizado na área de Desenvolvimento de Sistemas.

O objetivo é mostrar meus conhecimentos, apresentar meus projetos e compartilhar um pouco sobre meus interesses profissionais.

## 👨‍💻 Sobre mim

Meu nome é Israel Cardoso dos Santos Lima, sou estudante do curso de Desenvolvimento de Sistemas na Etec de Mogi Mirim.

Tenho interesse na área de tecnologia e programação e busco desenvolver minhas habilidades para me tornar um profissional qualificado.

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5:** estruturação das páginas e conteúdos.
- **CSS3:** estilização, cores, layouts e responsividade.
- **JavaScript:** interatividade e navegação entre as seções.

## ⚙️ Funcionalidades

O portfólio possui as seguintes funcionalidades:

- Navegação entre diferentes seções sem recarregar a página.
- Menu de navegação com abas interativas.
- Menu responsivo para dispositivos móveis.
- Exibição da biografia pessoal.
- Apresentação de qualidades profissionais.
- Exibição de habilidades técnicas.
- Apresentação de trabalhos e projetos escolares.
- Área de contato.
- Atualização automática do ano no rodapé.

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:

- Computadores.
- Tablets.
- Celulares.

Em dispositivos móveis, o menu horizontal é substituído por um botão de menu, facilitando a navegação.

## 🎯 Objetivo de aprendizado

Este projeto faz parte do meu desenvolvimento como estudante de Desenvolvimento de Sistemas.

Durante sua criação, pude praticar conceitos de:
